User message → TurnRun lifecycle

Current hosted Telegram path. Solid arrows carry accepted domain events; dashed arrows are optional branches or ownership fences.

canonical hierarchy

TurnRun → Segment → Frame → Bubble. A move is intent, a segment is one decoder trajectory, a frame is validated outward text, and a bubble is connector rendering.

durability boundary

Inbound messages are checkpointed before generation. Every visible frame becomes provisional durable state before it crosses the sandbox boundary and reaches Telegram.

correctness boundary

Generation ID and revision fence every write and send. Physical cancellation is best effort; superseded work cannot regain authority merely because it finishes later.
